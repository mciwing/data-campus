# 6. Rollenbasiertes Prompting

Indem das Modell eine **bestimmte Rolle** einnimmt, verändern sich Blickwinkel, Wortwahl und Bewertungsmaßstäbe. So lassen sich dieselbe Frage aus völlig unterschiedlichen Perspektiven beleuchten.

---

## Inhalte dieses Kapitels

- **Experte** – fundierte, fachliche Einschätzung
- **Investor** – Fokus auf Wirtschaftlichkeit, Risiko und Skalierbarkeit
- **Kunde** – Sicht auf Nutzen, Bedürfnisse und Akzeptanz
- **Konkurrent** – kritische Perspektive auf Wettbewerbsvorteile und Schwächen
